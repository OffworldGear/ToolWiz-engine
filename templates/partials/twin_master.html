Master Library builder

Merge every tool library you have into one master tool list, then build one Fusion-importable library per material set: the same tools, each with ToolWiz presets for the materials and strategies you pick. ToolWiz presets are tagged, so a rebuild replaces only them and never your own presets. Every built library is audited and presets with a STOP finding are dropped.
